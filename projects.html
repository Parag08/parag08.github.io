Operations product · Valeo Health

Logistics Valeo

The same day under Excel, v1 and v2, then hub siting and capacity. Rebuilt on synthetic data.

Problem. Home-visit dispatch ran on Excel. Operations captured only 60–70% of booked orders, and nurse–driver pairs drove long, empty routes.

What I did. Sat with the dispatchers, then shipped a tool built around their day: which orders the fleet can take, the order of each pair’s visits, and where idle pairs should wait. Operations moved onto it fully within a week.

Result. Measured at Valeo: ~23,000 km and ~AED 12,400 saved a month. The demo is a rebuild on synthetic data, so the logic can be shown publicly.

  • 80–90%orders captured, up from 60–70%
  • ~25%fewer km per order
  • 1 weekto full adoption by ops

Personal product · Live

JobSearch

The whole loop on one card, then interview prep on an application. Demo workspace.

Problem. A job search is one loop: find roles, tailor the CV, prepare, interview. But each step lives in a different tool, so the real work happens in spreadsheets and copy-paste.

Key decision. Build around the loop, not the steps. AI suggests CV changes as a diff against a master CV that the user reviews, so they stay in control of every line. Interview practice is scored, and case interviews run live.

Constraint. It runs entirely on free tiers, so it costs nothing to operate.

  • 6stages in one loop
  • ₹0monthly running cost
  • 581automated tests

AI product · Customer support

Support agent stores can trust

Demo store with the pipeline inspector open. Live model, real replies.

I want to return order SS90002

Order SS90002 was delivered on September 14, 2026, which is outside our 30-day return window, so I can't start a return or exchange for it.

return_request 0.95policy: denyRETURN_WINDOW_EXPIRED

Problem. Online stores want AI support for sizing, order tracking, returns and cancellations. But they can’t risk a chatbot that invents a refund policy or can be talked into one.

Key decision. The model only understands the request and writes the reply. Written store rules make every decision, and every message is checked for prompt injection first. Stores connect their own order system through standard plug-in points.

  • 0refunds or returns decided by the AI
  • 5plug-in points for a store’s systems
  • 181automated tests
